# خطة التنفيذ المعتمدة — adrik-mobile

**الهدف:** APK شخصي مستقر للاستخدام اليومي.
**الكود:** `adrik-personal` → `main` في `Mayzar-Alzamel6/Adrik`.
**شرط:** لا `eas build` قبل موافقة صريحة.

## إصلاحات المؤقت والإشعارات
1. المؤقت محسوب من `focusEndsAt` محفوظ في التخزين — يعمل مع زر الرئيسية، قفل الشاشة، والإغلاق الكلي.
2. إشعار ثابت أثناء الجلسة: "🎯 اسم المهمة" + عدّاد تنازلي حيّ (`@notifee/react-native`، showChronometer).
3. إشعار انتهاء بصوت واهتزاز (قناة High Importance): "✅ انتهت جلسة: اسم المهمة".
4. إذا انتهى الوقت خارج التطبيق → تُسجَّل الجلسة مكتملة عند العودة + رسالة "انتهت الجلسة".
5. الإيقاف المؤقت: إلغاء الإشعارات + حفظ المتبقي. الاستئناف: `focusEndsAt` جديد + إعادة جدولة.
6. طلب إذن الإشعارات عند أول تشغيل.

## البيانات
7. تصدير/استيراد JSON من الإعدادات (كل المتاجر) عبر المشاركة، الاستيراد استبدال كامل بعد تأكيد.

## إضافات البروتوكول (USAGE_PROTOCOL_INTJ.md)
8. تحذير عند بدء كتلة 90m على مهمة `drain` + اقتراح تأجيلها لآخر اليوم.
9. تنبيه "اكتفيت" بعد الكتلة العميقة الثالثة.
10. مؤقت استراحة 20 دقيقة تلقائي بعد كل كتلة + إشعار "عُد".
11. زر 💡 في FocusCard لالتقاط فكرة إلى Vault بنقرة والعودة للكتلة.
12. إشعاران يوميان قابلان للضبط: صباحي (NeuroGate) ومسائي (الإغلاق).
13. أهداف Velocity ≥ 70% و Quality Gate ≥ 80% في CompletionPanel بتلوين أحمر/أخضر.
14. خانة "🔋 شحن" يومية ضمن عادات المساء.
15. إشعار أسبوعي للمراجعة.

## ثوابت (لا تتغير)
- `drain` واحدة يومياً، تنبيه 30%، قفل Vault 48 ساعة بلا تجاوز، كتل 90/60/45 و20 للانهيار، نبرة المدرّب، DoD إلزامي دائماً.
- المدرّب الذكي: المفتاح كما هو (استخدام شخصي).

## التحقق
`npx tsc --noEmit` · `npx expo lint` · `npm test` → ثم طلب موافقة قبل `eas build --platform android --profile preview`.

## مؤشر الإنجاز والضبط التلقائي
16. **دقائق العمل العميق المنجز** يومياً: كتل مكتملة على `genius`/`neutral` اجتازت DoD (تُستبعد الملغاة والمسقطة).
17. **نسبة الضفادع المنجزة** أسبوعياً: أيام اجتاز فيها ضفدع الأولوية #1 الـ DoD ÷ أيام الأسبوع.
18. العرض: رقم اليوم في المحطة المسائية + اتجاه 7/30 يوماً في CompletionPanel.
19. مدخلات الضبط (آخر 7 أيام): نسبة إكمال الكتل، عدد RCA C، Energy Flow Index.
20. قواعد الضبط:
    - رفع: إكمال ≥ 90% و RCA C = 0 واستنزاف < 20% → كتلة إضافية أو 60→90.
    - ثبات: إكمال 70–90%.
    - خفض: إكمال < 70% أو RCA C ≥ 3 أو استنزاف > 30% → كتلة أقل أو 90→60.
    - سقف مطلق: 4 كتل عميقة يومياً.
21. التعديل يُعرض اقتراحاً في المحطة الصباحية (قبول/رفض بنقرة)، لا تغيير صامت.
22. تنبيه "اكتفيت" (بند 9) ديناميكي حسب الحد الحالي (2–4).

## الأولويات الثابتة المرتبطة بالمشاريع
23. الأولوية **ثابتة (Anchor)** تستمر يومياً حتى تُغلق يدوياً — مثال: "دراسة الألمانية A2".
24. حد أقصى 3 أولويات ثابتة.
25. كل أولوية مرتبطة بمشروع واحد (1:1).
26. تحت كل أولوية زر "＋ سحب مهمة" يعرض مهام TODO من مشروعها فقط؛ حتى 3 مهام يومياً لكل أولوية.
27. الأولوية لها هدف بعيد + تاريخ؛ كل مهمة مسحوبة لها DoD خاص.
28. تصنيف الطاقة على المهمة؛ حد `drain` الواحد يُحسب على المهام.
29. بدء الكتلة يختار مهمة من تحت أولوية؛ المؤقت والإشعار: "🎯 الأولوية › المهمة".
30. المهمة المنجزة → DONE في المشروع الأصلي. غير المنجزة → تُرحّل لليوم التالي تحت الأولوية بعلامة "مُرحّلة ×N"؛ عند 3 ترحيلات يقترح التطبيق Conscious Drop.
31. الضفدع = أول مهمة تحت الأولوية #1؛ إعادة الترتيب بالسحب.
32. المشاريع غير المرتبطة بأولوية تبقى في شاشة المشاريع ولا تظهر في شاشة اليوم.
