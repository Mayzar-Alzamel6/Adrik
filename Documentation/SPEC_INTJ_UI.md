* **التاريخ:** أكتوبر 2026

* **المسار المستهدف:** `adrik-personal/`

---

## 1. الافتراضات الحاكمة (Surface Assumptions)

1. **عزل الحالة (State Isolation):** لتجنب أي خطر لتعديل أو كسر المتجر الضخم للتطبيق (`useAppStore.ts` الذي يحتوي على 1800+ سطر)، سيتم بناء متجر Zustand معزول ومستقل تماماً `useIntjProtocolStore.ts` يخزن بيانات الجلسة (المؤقت النشط، عقود الكتل، وسلة الأفكار) في `localStorage` مع حفظ السجل اليومي.
2. **الدمج غير التدخلي في `TodayView.tsx`:** إضافة خيار رابع في شريط المحطات (`SegmentedControl`) باسم "بروتوكول INTJ"، مع فحص رابط الصفحة لقراءة معيار `?station=INTJ_PROTOCOL`.
3. **مشغل ويندوز (`start-today.bat`):** التحقق من تشغيل خادم Next.js على المنفذ `3334`، وفتح نافذة تطبيق المتصفح مباشرة على رابط:  
   `http://localhost:3334/app?station=INTJ_PROTOCOL`
4. **بقاء لوحة التحكم دون أي تغيير:** المحطات الثلاث السابقة (تهيئة الصباح، التركيز، والمساء) وباقي الصفحات (`/review`, `/vision`, `/tools`) تظل تعمل بنفس منطقها ومكوناتها الأصلية بنسبة 100%.

## 2. الهدف ونطاق العمل (Objective & Scope)

### الهدف:
توفير تجربة بصرية تفاعلية كاملة لبروتوكول أدرك عمرك الخاص بـ INTJ-A داخل تطبيق الويب القائم، بحيث يتكامل مع لوحة التحكم كخيار مخصص يمكن الوصول إليه بضغطة زر واحدة عبر `start-today.bat`، دون المساس بأي ميزة حالية.

## 4. تفاصيل الواجهة التفاعلية (UI Specifications)

1. **شريط الكتل الثلاث (Block Selector):**
   * الكتلة 1: **90 دقيقة** (الضفدع الأكبر).
   * الكتلة 2: **60 دقيقة** (ثانوية حاسمة).
   * الكتلة 3: **45 دقيقة** (إغلاق التزامات).
   * مؤقت عد تنازلي حي مع أزرار (بدء / إيقاف مؤقت / إنهاء).
2. **عقد ما قبل الانطلاق (Pre-flight Contract):**
   * إدخال إجباري لمعيار الإغلاق الثنائي (Done When).
   * إدخال صريح لما هو خارج النطاق (Out of Scope).
3. **معالج الأعطال السريعة (2-Min RCA):**
   * يظهر فور الضغط على "تعثر الكتلة" أو انتهاء الوقت دون تحقق الشرط.
   * خيارات سريعة: Bug A (هندسة مفرطة) / Bug B (ضبابية معيار) / Bug C (طاقة مستنزفة) مع إظهار الترقيع الفوري فور النقر.
4. **سلة الأفكار (Parking Lot):**
   * حقل إدخال سريع لإضافة أي فكرة طارئة بنقرة Enter وتخزينها في قائمة اليوم.

## 5. ضوابط وحدود النظام (Boundaries)

* **Always:** عزل متجر البروتوكول الجديد عن متجر التطبيق العام؛ التحقق من عمل الخادم قبل فتح المتصفح؛ دعم اللغة العربية واتجاه RTL وتناسق الألوان والخطوط مع هوية Adrik.
* **Ask First:** أي تعديل على مكونات التركيز القديمة (`FocusCard`, `PrioritiesCard`).
* **Never:** تعديل أي مخطط في قاعدة البيانات Prisma؛ تعديل أي ملف في مسارات الصفحات الأخرى.

## 6. معايير النجاح (Success Criteria)

1. فتح `start-today.bat` يطلق المتصفح فوراً على `http://localhost:3334/app?station=INTJ_PROTOCOL`.
2. يتم عرض واجهة "بروتوكول INTJ" مباشرة وبشكل سلس.
3. التبديل بالماوس بين المحطات ("تهيئة الصباح" / "التركيز" / "المساء") يعرض المحطات الأصلية دون أي خطأ.
4. استقرار الـ Build واجتياز تدقيق TypeScript دون أي تحذيرات.
